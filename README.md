# WeightBox

GPU and Model Compatibility Observatory.

Data Management 2025/2026 project.

## Tech Stack

### Data & Backend

- PostgreSQL
- Python
- Pandas
- FastAPI
- SQLAlchemy
- Psycopg

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts

### Infrastructure

- Docker
- Docker Compose

## Project Structure

- `database/` - PostgreSQL warehouse schema and OLAP queries
- `etl/` - Python ETL pipeline
- `backend/` - FastAPI backend
- `frontend/` - Next.js application
- `data/` - Local raw and processed datasets
- `docs/` - Documentation
